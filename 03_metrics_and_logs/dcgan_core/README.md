# DCGAN core evidence package

This folder contains the DCGAN-only metric catalog and provenance copied from `dcgan_lab/results/figures/`.

- `dcgan_core_metrics.csv`: readable ASCII-named copy of the 49-row historical metric index covering Phase 1, Phase 2, Phase 3, and CLIP.
- `dcgan_result_catalog.csv`: readable ASCII-named copy of the source-result file catalog.
- `全实验指标汇总.csv` and `全实验数据清单.csv`: original filenames retained for provenance.
- `figure_manifest.json`: the source figure manifest, preserved for traceability.
- `figure_audit.csv`: public-snapshot audit of manifest entries versus files physically present in the source directory.

The public charts are in [`04_visual_assets/dcgan_core/`](../../04_visual_assets/dcgan_core/). Only seven DCGAN SVGs were present in the source directory at the time of this snapshot; missing manifest entries are not reconstructed or presented as completed evidence.
