# Task 3 — FP32 / FP16 / INT8 量化评估报告

## 1. 结论摘要

任务三的 03A–03D 实验产物已经形成完整的量化评估链路，03E 只做本地汇总，不重复运行 Kaggle 实验。报告使用 03D 已落盘的 CSV/JSON 结果，因此不依赖未下载的 `real_fid_standard_stats.npz`。

- FP16 基本保持 FP32 质量：标准 FID 仅增加 `0.0030`，模糊率不变，FP16 相对 FP32 的输出 RMSE 为 `0.000566`。
- INT8 明显改变生成分布：标准 FID 从 `29.9911` 增至 `35.3198`（`+5.3287`），模糊率从 `12.0%` 增至 `12.5%`，输出 RMSE 为 `0.026279`。
- INT8 的绝对误差主要落在 LL，但按子带自身能量归一化后，HH/LH/HL 的相对误差最大，说明高频细节对 INT8 更脆弱；这支持“高频子带截断/尺度误差导致细节损失”的解释，但不能据此声称高频误差在绝对值上占主导。
- INT8 速度收益明显，但当前 PTQ 不适合作为最终部署质量方案；后续应优先采用混合精度、逐通道校准和 QAT。

## 4. 量化误差与高频子带分析

### 4.1 端到端输出误差

| 对比 | MAE | RMSE | 最大绝对误差 |
|---|---:|---:|---:|
| FP16 vs FP32 | 0.000357758 | 0.000566024 | 0.0196114 |
| INT8 vs FP32 | 0.012811564 | 0.026278567 | 0.946010 |

INT8 的 MAE 约为 FP16 的 35.8 倍，RMSE 约为 46.4 倍，且存在接近完整 `[0,1]` 输出范围的极端误差点。这与 INT8 FID 恶化和 Laplacian 响应下降相互印证。

### 4.2 Haar 子带相对误差

| 对比 | LL MAE / 相对误差 | LH MAE / 相对误差 | HL MAE / 相对误差 | HH MAE / 相对误差 |
|---|---:|---:|---:|---:|
| FP16 vs FP32 | 0.000557 / 0.044% | 0.000348 / 0.399% | 0.000242 / 0.495% | 0.000212 / 0.581% |
| INT8 vs FP32 | 0.020885 / 1.657% | 0.011248 / 12.885% | 0.008463 / 17.333% | 0.007165 / 19.691% |

解释：INT8 的 LL 绝对 MAE 最大，因为 LL 能量最大；但 HH 的误差占其自身基线能量 `19.691%`，明显高于 LL 的 `1.657%`。因此更严谨的结论是：INT8 同时引入了低频幅值误差和更严重的高频相对失真，后者容易表现为发丝、轮廓、眼睛等细节变软或纹理不稳定。现有数据不支持“高频绝对误差大于 LL”的更强表述。

### 4.3 对 INT8 FID/模糊率恶化的原因定位

1. INT8 的激活/权重离散化误差在多层 ConvTranspose 累积，最后经 Tanh 压缩到图像范围，少量异常通道会造成局部饱和或颜色/边缘偏移。
2. 高频子带的基线幅值小，使用共享张量尺度时，同样的量化步长会占据更大的相对比例；HH/LH/HL 的相对误差远高于 LL。
3. 生成器最后几层负责把上采样特征转换为 64×64 的局部纹理，INT8 误差在那里更容易转化成 Laplacian 响应下降与 FID 分布偏移。
4. 本次结果不能把所有 FID 增量单独归因于 HH 截断：频域表明 LL 的绝对误差最大，且 Edge density ratio 变化很小。因此应将原因表述为“全网络累积量化误差 + 高频相对尺度失真”，而不是单一高频子带因素。

## 5. 后续优化建议

- 对最后一个 ConvTranspose、输出前激活以及高频敏感层保留 FP16/FP32，先做混合精度 INT8。
- 采用逐通道 weight scale，并针对激活使用 percentile/entropy 对比校准；不要只依据全张量最大值。
- 将 100 张真实动漫头像扩充为覆盖发色、肤色、线稿、背景和高对比边缘的代表性校准集。
- 将 Haar 高频统计纳入校准/QAT 监控，重点约束 LH/HL/HH 的误差，而不仅是全图 MSE。
- 用 QAT 重新学习量化 scale，并把 Standard FID、模糊率和 LPIPS 作为联合验收条件。
